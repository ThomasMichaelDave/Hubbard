# Hubbard Dual-Gauge Coil Calculator (Streamlit GUI)

A web-based calculator for designing and analyzing dual-gauge electromagnetic coil systems inspired by the Hubbard device concept. This tool supports different wire gauges for inner and outer coils, calculates inductance, resistance, capacitor wrapping, and resonance.

## Features

- **Dual Wire Gauge Support**: Configure different wire areas for inner and outer coils.
- **Capacitor Wrap Calculator**: Simulates wrapping around the entire device and computes plate area.
- **LC Resonance Calculator**: Calculates the resonant frequency of the outer coil and capacitor.
- **Live Browser Interface**: No need for desktop GUIs — runs entirely in your browser.
- **Easy to Modify and Extend**: Clean Python/Streamlit codebase.
